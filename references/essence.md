# Path 的界面与交互精华

> 文档类型：设计分析（复刻与延伸参考）。适用范围：用 path-ui skill 复刻 Path 的效果，或按 Path 的思路做它没有的东西。
> 依据：Path 官网 2012 存档（产品说明、首页演示视频）、官方博客 Path 2 配图、Brian Lovin 2016 年 Path iOS 拆解的 17 段录屏（逐帧看过）、爱范儿 2011/2018 两篇、开源复刻 AwesomeMenu / DCPathButton / TimeScroller 源码。核对日期 2026-11-14。
> 录屏约 30 帧/秒，实测的时间有 ±33ms 误差；具体数字见 [motion-spec.md](motion-spec.md)。

## 一句话

Path 把「只给最亲的人看的小圈子」做成一本会动的日记：一条竖着的时间线、一个能发所有东西的加号、一只滚动时总在手边报时的钟。

## 七条取向（为什么这样做）

1. **私密是产品本身。** 好友上限 50 人，后来放到 150 人；默认只有圈子里的人看得到。官方把这个圈子比作 “the dinner table at home”。落到界面上，就是每条下面写「谁看过」（Seen），主页写「谁来过」（Visits），引导卡片专门讲隐私。
2. **时间是主轴，不是热度。** 内容按时间排在一根竖线上。封面和头像下面有一行「此刻」：在哪、几点、天气（例：San Francisco · Evening, 70°F）。滚动时右边有一只钟，指针转到正下方那条的时间。整套设计都在帮人回答「那是什么时候」。
3. **一个按钮发所有东西。** 官方给这个加号起名 Chooser，照片、和谁在一起、在哪、在听什么、想说什么、睡了/起了都从这里发。每种「时刻」有固定的图标和颜色，在发布菜单、时间线上的小圆、搜索筛选、加载指示里反复出现，同一套符号一路贯穿。
4. **情绪回应，不是点赞。** 五种回应：微笑、大笑、惊讶、难过、爱。点了就在原地冒出一块深色浮层，选完浮层收起，回应落到这条下面。后来的贴纸也是同一个入口。
5. **东西有重量和弹性。** 弹窗从上面掉下来、晃两下才停；关的时候歪着往下摔。菜单图标冲过头再弹回来，一边走一边转。星标点亮时弹一下。所有动作都很短（120–500ms），并且只在状态变了的时候出现，平时界面是静的。
6. **没人注意的地方也做了。** 信息流尽头有一个压在纸上的小装饰。加载时是一排浅浅压印的类型图标轮流变深，不用转圈。地图页的指南针会跟着地图转。下拉刷新时，时间线的线头被拉成一滴水，拉过头就断开。
7. **颜色很省，但每一种都有意思。** 大面积是暖白的纸色（Path 4 是 #F6F0EB，Path 2 是 #F3EEE9）。品牌红只给「新建」和「欢迎」；每种内容一个类型色，只出现在它的字形、小圆和筛选块上；状态色只有一个，私密是蓝；浮层和时钟用近黑。细则见下面的规则 11–13。

## 两个时代的骨架

| | Path 2（2011.11–2013） | Path 4（2014–2016） |
| --- | --- | --- |
| 质感 | 拟物：亚麻布纹红顶栏 #BB2E1C、纸纹底、投影 | 扁平：纯色橘红 #F33F12、平底、少量投影 |
| 加号 | 左下角浮着，图标沿四分之一圆弹出（6 个） | 底栏正中，图标沿 120° 上半弧弹出（5 个），背景压暗 60% |
| 导航 | 左滑出菜单、右滑出好友 | 底栏 5 格（中间是加号） |
| 时间线 | 头像在左，竖线上是类型小圆，右边是回应按钮 | 同一结构，扁平化；顶上加搜索框 |
| 回应 | 五张脸的深色浮层 | 五张脸加贴纸格子，外加评论框 |
| 弹窗 | — | 掉落 + 摔出；引导卡片用品牌色整卡 |

复刻时先问清是哪一代：两代的菜单位置、弧度、节奏都不一样，混在一起就哪一代都不像。

## 模式目录

每条都写了「是什么 / 关键细节」。代码在 `assets/path-kit/`，函数名写在括号里。

1. **发布按钮**（`radialMenu`）：点加号，加号转成叉；图标从加号后面冲出去，越过终点再弹回来，同时自转。选中一个，它放大 3 倍淡掉，其余的缩没，然后进入发布页。点空白处或 Esc 收回，收回时倒着来。
2. **竖线时间线**（CSS `.pk-timeline` / `.pk-moment`）：作者头像（圆角方块）、竖线上的类型小圆（圆外一圈纸色描边，把线断开）、正文（粗体是人名和地名）、灰色小字是情境、最右是回应按钮。
3. **封面 + 头像 + 此刻**（`coverHeader`）：大封面，左下是头像和「此刻」一行。往上滚：头像和文字在前 60% 淡掉，封面以一半速度移动，最后剩一条当顶栏，顶栏标题在最后 30% 淡入。往下拉：封面放大。
4. **滚动时钟**（`timeScroller`）：滚动时右边出现一个近黑标签，尖角指向滚动条的滑块，跟着滑块上下走。左边是白底红针的小表盘，指针用约 300ms 转到新时间，时间往后就顺时针，往前就逆时针。右边是粗体钟点，下一行是日期：当天不写，一周内写星期几，今年写几月几日，更早的带年份。停手 1 秒后淡出。
5. **情绪回应**（`reactionPicker` / `popIn`）：深色浮层贴着按钮出现，约 200ms 淡入、从按钮方向放大；五张脸一个个冒出来，略微冲大再回到原大。下面一行带锁的「2/4 位家人看过」。选完，被选的那张先放大，再整块淡出，回应弹进这一条下面。
6. **掉落弹窗 / 引导卡片**（`dropModal` / `pagerDots`）：卡片从上方落下，约 360ms 停稳，期间像钟摆一样左右晃（约 -4°→+3°→-1°→0）。背景压暗约 72%。关闭时往右歪约 8°，越落越快，约 300ms 摔出底部。引导卡片是整张品牌色，横向翻页，下面有圆点。
7. **下拉刷新**（`pullToRefresh`）：在顶部往下拉，列表跟着下来，封面放大；时间线的线头被拉成一滴水（上细下圆）。拉过阈值，水滴断开，缩成一个品牌色的点；松手后列表弹回，点开始跳动；加载完，点放大淡掉。
8. **星标**（`popToggle`）：点亮时从 0 弹到约 1.35 倍，再落到 0.9，最后停在 1；取消时鼓一下。
9. **压印加载 / 信息流尽头**（`relayLoader` / `.pk-feed-end`）：图标和装饰的颜色只比纸深一点，下沿带一道白色高光，看起来像压进纸里。加载时一排图标每 170ms 换一个变深。
10. **就地提示**：新用户第一次进来时，加号旁边冒出一句提示（例如「记下一个时刻」）。弹窗都用同一套掉落/摔出，整个 App 只有这一种弹窗动效。

## 规则：Path 没有的东西怎么做

上面十个模式是 Path 做过的东西。下面十四条，前十三条是从这些模式里倒推出来的共同做法（1–10 管动作和结构，11–13 管颜色和字形），第 14 条管控件状态，是借来的，用来做 Path 没有的东西：设置页、通知、上传、购物清单……每条写了 Path 里的出处（括号里的编号是文末「素材」里列的拆解录屏）、推到新东西上怎么用、用错是什么样。

这些规则是归纳出来的，不是 Path 官方写下的设计原则。交付时，按规则推出来的部分要和照搬 Path 的部分分开说。

### 1. 从哪来，回哪去

- **Path 里**：发布菜单的图标从加号后面冲出去，收回时回到加号（03）；回应浮层从心形按钮那一侧放大出来（06）；时钟标签贴着滚动条的滑块走（14）；下拉刷新的水滴是从时间线的线头拉出来的（16）。
- **推到新东西**：先问「它是谁叫出来的，要去哪」。面板从叫出它的按钮长出来；新条目从触发它的按钮飞进列表；被归档、删掉的东西飞向它要去的地方；收起时沿原路回去。零件：`flyFrom`、`flyTo`、`growFrom` / `shrinkTo`。
- **用错的样子**：点了右上角的铃铛，提示却从左下角滑进来；所有面板都从屏幕正中淡入。

### 2. 方向有含义，重力朝下

- **Path 里**：时间往后指针顺时针转，往前就逆时针（14，TimeScroller 源码）；弹窗从上面掉进来，也往下摔出去（01、04）；菜单收回时倒着走、倒着排（AwesomeMenu 源码）；加号转成叉，关上再转回来（03）。
- **推到新东西**：前进和后退、加和减、开和关各定一个方向，反过来的操作就倒着放。来的东西从上方或从源头来，扔掉的东西往下或往目的地走。零件：`turnTo`、`dropIn` / `fallOut`、`fly` 的 `windup`。
- **用错的样子**：撤销和执行放同一段动画；弹窗从下面升上来，又从上面飞走。

### 3. 有重量，但很短

- **Path 里**：图标冲过终点 10px 再回落 5px（Path 4）；星标 0 → 1.35 → 0.9 → 1；弹窗 -4° → +3° → -1° → 0；摔出去越落越快。全部在 120–500ms 以内（[motion-spec.md](motion-spec.md) 第 1、4、5 节）。
- **推到新东西**：到位时冲过一点再停，离开时加速。东西越大，幅度越小：小图标可以冲 10px、放大到 1.3 倍，整张卡片只晃一两度。时长留在 120–500ms，网页上靠近 300ms。零件的 `over`、`back`、`peak`、`swing`、`tilt` 都跟着强度缩放。系统开了「减少动态效果」时不移动、不缩放、不转，换成淡入淡出或直接到位，东西照样出现、消失、状态照样变（kit 已经这么做；做法借自 apple-design）。
- **用错的样子**：超过 0.6 秒的弹簧；晃三四下才停；大面板也冲过头 20px。

### 4. 热闹和颜色只给一处

- **Path 里**：最花的效果（冲出、自转、压暗）和品牌红都给了加号，那是整个 App 最核心的动作「记下一个时刻」（03 在原文里的小节名就叫 Making Path famous）。回应、星标只是冒一下；时间线和时钟本身不弹。品牌红只在顶栏、加号和少数强调处，类型色只在小圆里（motion-spec 第 7 节）。
- **推到新东西**：先挑出这个产品最核心的一个动作，热闹和强调色留给它；其余的按下面的「动作分五级」往下降。
- **用错的样子**：每个按钮都是品牌色、都会弹；为了「像 Path」，把扇形弹出套到设置项、筛选、分享上。

### 5. 一类事一种动作，一种东西一个符号

- **Path 里**：整个 App 只有一种弹窗动效，登录、功能引导都是掉进来、摔出去（01、04）。每种时刻有固定的图标和颜色，发布菜单、时间线上的小圆、搜索筛选、加载指示用的是同一套（03、10、11）。
- **推到新东西**：每一类事件（要用户确认的打断、新内容出现、东西离开）定一种动作，全站复用。每种内容类型定一个图标、一个颜色，入口、列表、筛选、加载、空状态都用这一套。
- **用错的样子**：删除确认从上面掉下来，设置弹窗从右边滑进来，登录又是淡入；类型在入口是图标，在列表里变成文字标签，在筛选里又换了颜色。

### 6. 平时是静的

- **Path 里**：不操作的时候，时间线、封面、按钮都不动；唯一的循环动画是压印加载（11）；时钟停手 1 秒就淡掉（14）。
- **推到新东西**：动效只回应状态变化：用户操作了、新内容到了、正在加载。循环只在真的在等的时候用，等完立刻停。新内容到了提示一次，不一直闪。
- **用错的样子**：铃铛一直晃；按钮像呼吸一样明暗；背景缓慢漂动；未读数字一直跳。

### 7. 就地发生，不把人带走

- **Path 里**：回应在点的地方原地冒出来，选完落到这一条下面（06）；在个人页上点头像、点封面就直接改（07）；报时贴在手边的滚动条上（14）；新手提示冒在加号旁边。
- **推到新东西**：小事（选一个、拨一个开关、看结果）在原处完成，反馈出现在触发它的控件旁边。只有真要打断、要用户拿主意的，才用弹窗。能撤销就不确认：只有不常见、改不回来的操作（清空、永久删除）才弹确认；其余先做，在原处给「撤销」（这一句借自 apple-design）。
- **用错的样子**：拨了一个开关，页面顶上弹出全局提示「保存成功」；点个回应跳到新页面。

### 8. 先回答「什么时候、谁看得到」

- **Path 里**：每一条下面都有时间和情境（地点、天气）；回应浮层底下写「Seen by 2 of 4 friends」（2013 截图）；个人页有「谁来过」。时钟的日期写法：当天不写日期，一周内写星期几，今年写几月几日，更早的带年份（14，TimeScroller 源码）。
- **推到新东西**：一条内容、一次操作，都交代时间（用上面这套相对写法）和范围（谁看得到、给谁的、谁设的）。
- **用错的样子**：只写「2026-11-14 09:12:33」；分享出去不知道谁能看到；提醒不写是谁设的。

### 9. 跟手，门槛看得见

- **Path 里**：下拉刷新时列表跟着手指走，越拉越沉；拉过门槛，水滴「啪」地断开变成一个点，松手才刷新；没过门槛松手就弹回去（16）。
- **推到新东西**：拖动类操作（滑动归档、拖动排序、拖着调数值）要跟手、带阻尼。过门槛时给一个看得见的变化（断开、图标冒出来、颜色变），没过就弹回原处。键盘和读屏用户要有一个按钮能做同样的事。零件：`rubber`、`pop`。
- **用错的样子**：拖过一段看不出来的距离，突然就执行了；松手后硬切到位；只有手势，没有按钮。

### 10. 没人注意的地方也做

- **Path 里**：加载时是一排浅浅压进纸里的类型图标轮流变深，不用转圈（11）；信息流到底有一个压印的小装饰（15）；地图上的指南针跟着地图转（09）。
- **推到新东西**：加载、空状态、列表到底、离线，都用同一套类型图标做成压印样式（`.pk-deboss`、`relayLoader`），再配一句人话。等待的节奏：等待通常很短时晚 300–500ms 再露面，免得一闪而过；露面了至少留 500ms；一直在动，不能卡住，减少动态效果时也照样轮流变深。数据还没到时先放占位，不放一片空白。kit 的 `relayLoader` 默认晚 400ms、留 500ms（经验值借自 apple-design）。
- **用错的样子**：空状态只有一行灰字「暂无数据」；到处是浏览器默认的转圈。

### 11. 底是中性的，颜色留给内容和意思

- **Path 里**：
  - 纸色 #F6F0EB 几乎没有彩度（OKLCH 彩度 0.009），正文是暖深灰，不是纯黑。白卡只给用户自己写的文字帖；全屏颜色最多的是照片和封面（03）。
  - 到了 Path 4，时间线上很多条只剩一个灰点：自动记下的地点是深灰点，想法是浅灰点（03）。
  - 品牌橘红只出现在「新建」和「欢迎」上：顶栏、加号、发布页的顶栏、新手引导的整张卡片、「Create a moment」提示（02、03、13）。
  - 状态色只有一个：私密是蓝。选「只给内圈」「只给自己」时，星标和锁一起变蓝（13；2013 截图里锁也是蓝）。别的状态都不上色。
- **推到新东西**：先把底做成暖中性（纸、白卡、暖深灰的字）。颜色只给三样：最核心的入口（品牌色）、内容类型（类型色）、一个真正要提醒的状态（只挑一个）。其余状态不上色，用字说。
- **用错的样子**：成功绿、警告黄、信息蓝、错误红全都上；卡片铺品牌色底；正文用纯黑；界面比照片还花。

### 12. 一类东西一个颜色，按联想选，一路带着走

- **Path 里**：
  - 地点蓝、音乐橙、想法绿、睡眠深紫、照片（筛选里）青；搜索筛选里日期红、春绿、夏黄、秋橙、冬灰蓝（03、10、11；取色见 [motion-spec.md](motion-spec.md) 第 7 节）。
  - 色相按联想挑：夜是深紫，夏是亮黄，冬是冰灰蓝。
  - 彩度都高（OKLCH 0.13–0.22），明度不拉齐、跟着联想走：睡眠最暗（L 0.36），夏最亮（L 0.88）。
  - 同一个颜色有两种用法，看它压在什么上。压在压暗层上的是**白底配彩色字形**（Path 4 的发布菜单，白圆在暗处跳出来）；在纸上的是**彩色底配白字形**（搜索筛选块、时间线上的地点圆、Path 2 时间线的类型圆，还有 Path 2 不压暗的发布菜单）。
  - 内容自己就带颜色的类型不抢色：发布菜单里，相机字形是近黑 #383732，因为照片本身就是全屏最花的东西。
- **推到新东西**：
  1. 列出内容类型，每类按联想挑一个色相，要说得出和这类东西有关的理由（钱是绿、日程是蓝、家人是暖色……）。只说「和别的颜色拉得开」不算理由。照片、视频这类内容自己带颜色的，按 Path 用近黑或中性色，理由就是「颜色交给内容」。
  2. 色相之间拉开，彩度拉齐，明度可以跟着联想走。
  3. 压暗层上用白底彩字形，纸上用彩底白字形；这个颜色在入口、列表、筛选、加载里都一样。常驻在页面顶上的筛选条，如果每块都铺满颜色会太花，可以没选中时白底彩字形、选中时彩底白字形。这一条是推出来的：Path 的筛选块在单独的搜索页里，一屏全是彩色。
  4. 查对比度：白字形不低于 3:1，筛选块上的字不低于 4.5:1。不够就把底色加深（kit 的 `data-pk-contrast="more"`），黄这类浅色改用深色字。
- **用错的样子**：类型色只在入口出现，列表里换成文字标签；颜色按顺序轮着分（第一类蓝、第二类橙），说不出为什么；黄底白字。

### 13. 一套字形，换尺寸、换材质，不换形状

- **Path 里**：
  - 同一组实心剪影（地点针、相机、引号、月亮、音符、刀叉）出现在 44px 的发布菜单、筛选块、时间线上的小圆、压印加载里（03、06、10、11）。
  - 字形是一眼认得出的实物，实心、圆头、不描边，大约占圆的一半。里面的细节（针眼、镜头）是镂空的，所以放在白底和彩底上都成立。
  - 形状有分工：类型用圆，带字的筛选用胶囊。只有底栏用细线图标加小字，当前那一格换成实心（03 的底栏）。
  - 表情是唯一「可爱」的图标：黄圆脸、深色五官，心是红圆配白心（06）。
- **推到新东西**：先画字形表，再用。每个类型一个实物剪影：24 网格、实心、圆头、细节镂空。同一个字形用在入口、列表、筛选、加载、空状态。导航用细线，选中的那一格变实心。kit 的 `glyphSvg` 有一套按这个规范画的原创字形，可以直接用，也可以照着画。
- **用错的样子**：入口用一套图标库、列表用另一套；描边和实心混着用；细节用白色涂出来（放到彩底上会多出一块白）；直接用 Path 的原图标。

### 14. 按下就有反应，每种状态都说得清（借来的）

- **出处**：这一条不是从 Path 倒推的。Path 是手机 App，录屏里手指挡着、帧率也不够，看不出按下的样子；搬到网页上又必须补。做法借自 [JUNERDD/Atd](https://github.com/JUNERDD/Atd) 的 `apple-design` 的交互反馈规则（MIT）。
- **推到新东西**：
  - 按下 60ms 内就有变化（压下去一点、变暗），松手弹回。松手才执行，按下后拖出控件再松手就不执行（原生的 click 就是这样）。
  - 选中不能只靠颜色：加勾、实心和描边、加粗，至少再有一样。
  - 不能用的照样看得见：变淡、点不动，旁边一句为什么。别直接藏起来。
  - 「正在处理」放在控件自己身上：按钮变成「正在上传…」，晚一点再出压印图标；不在页面中间另起转圈，也不能重复提交。
  - 键盘焦点一定看得见。悬停只是锦上添花：触屏没有悬停，重要的东西不能藏在悬停里。
  - kit：加号、筛选块、星标、表情、菜单图标、回应按钮都有按下的样子（`path-kit.css` 第 9 节）。量点击区用 `PathProbe.hitAreas()`。
- **用错的样子**：按下去没反应，等结果出来才变；按下就执行，拖开也取消不了；选中只换了个颜色；禁用的按钮直接消失；转圈出现在页面正中，按钮还能再点。

### 动作分五级

规则 3、4、6 合起来，就是给每个状态变化挑一级动作。越往上越热闹，用的地方越少。

| 级 | 动作 | Path 里用在 | 推到新东西 | 零件 |
| --- | --- | --- | --- | --- |
| 1 | 冲出 + 自转 + 压暗 | 加号的发布菜单 | 整个产品最核心的入口，只有一个 | `radialMenu`、`fly` |
| 2 | 掉进来 / 摔出去 | 登录、功能引导 | 要用户停下来拿主意的：删除、清空、第一次的引导 | `dropModal`、`dropIn` / `fallOut` |
| 3 | 冒一下（1.15–1.35 倍） | 回应、星标、回应落到条目下 | 新出现的小东西；状态切换（完成、收藏、拨开关） | `pop`、`popToggle` |
| 4 | 长出来 / 淡入（≤ 200ms） | 回应浮层、时钟标签 | 面板、菜单、提示、就地反馈 | `growFrom`、`fadeIn` |
| 5 | 不动 | 时间线、封面、正文 | 内容本身、导航、排版、设置项本身 | — |

### 推一个新东西

1. 列出它所有的状态变化：出现、打开、选中、完成、出错、离开、等待、空、到底。
2. 每个变化问四件事：谁叫出来的、要去哪（规则 1）；正向还是反向（2）；有多重要，放第几级（4 和上表）；要不要打断用户（7）。
3. 用 path-kit 的零件拼，不另写一套曲线。零件的默认值不够用，就看 motion-spec 里最接近的那一项。
4. 配颜色和字形（规则 11–13）：底是中性的；每种内容类型一个色相、一个字形；品牌色只给最核心的入口；状态色最多一个。
5. 对一遍规则 5、6、10–14：同一类事是不是同一种动作；类型的颜色和字形有没有一路贯穿；平时是不是静的；等待和空状态做了没有；白字形的对比度够不够。
6. 交付时分三类说：照搬 Path 的（哪个模式）、按规则推的（哪一条）、规则推不出来你自己定的。

### 两个推出来的例子

在 `assets/path-kit/extend-demo.html` 里能点：

- **上传照片**：
  - 点上传后，按钮原地变成一排压印的类型图标，轮流变深（规则 7、10）。
  - 传完，新照片从上传按钮飞进相册，冲过一点再停（1、3）。下面写「刚刚 · 家里 4 个人能看到」（8）。
  - 传失败时要用户决定重试还是放弃，用全站唯一的那种掉落弹窗（5）。
  - 上传是这一页最重要的动作，所以只有它用强调色（4）。
- **滑动归档**：
  - 往左拖，条目跟着手、越拖越沉；过了门槛，归档图标冒一下（9）。
  - 松手，条目飞向底栏的「已归档」，那里的数字冒一下（1、3）。没过门槛就弹回原处。
  - 每条也有一个「归档」按钮，用键盘也能归档（9）。
  - 全部归档完，出现压印的空状态（10）。

## 不要照搬的

- **品牌资产。** Path 的标志、字标、贴纸画、封面照片、图标原图都不用，一律画原创的。要复刻的是行为和节奏，不是 Path 的外观本身。界面上也不写 Path 这个名字（标题、说明面板、读屏文字都算），出处写在代码注释和交付说明里。
- **发布按钮有专利。** Path 2013 年就「从菜单图标沿不同路径弹出多个子菜单图标、用来往社交网络发内容」申请了美国专利 US9448692B1（发明人有 Dustin Mierau、Dave Morin 等）。现在由 Kakao Corp / Path Inc 持有，状态 Active，预计 2034-07-16 到期。上线商用产品前，请法务看过权利要求再定。内部原型和学习不受影响。AwesomeMenu 的 README 也写明不要拿它去抄 Path。
- **Path 2 的 0.5 秒。** AwesomeMenu 每个图标走 500ms，再错开 36ms，6 个图标总共将近 0.7 秒，在网页上偏慢。网页优先用 Path 4 的 300ms。
- **可爱程度。** 贴纸、整圈自转、弹跳放在严肃场景会显得轻浮，用 `setIntensity` 降到 0.3–0.5。降的是幅度，不是时长：克制版照样掉进来、摔出去，只是晃得轻、歪得少。压在浅色页面上的弹窗，压暗也要跟着调浅（Path 的 0.72 是压在橘红上的）。
- **浅色底上的白字形。** Path 的黄、青、橙、绿底配白字形，对比度只有 1.4–3.1，图形要 3:1、字要 4.5:1，都不够。网页上用 kit 的 `data-pk-contrast="more"`：它把这几种颜色保持色相加深到够用，夏黄、冬灰蓝这类浅色改成深色字。
- **手机上的习惯。** Path 是手机 App：滚动指示靠手指、没有键盘、没有鼠标悬停。搬到网页上要补：滑块能拖、方向键和 Esc 能用、点外面能收。kit 已经补好了。
- **没量到的部分。** Path 2 的菜单有没有压暗、贴纸浮层的错开时间、下拉刷新的阈值，素材里都没量准，代码里标了「估」。
