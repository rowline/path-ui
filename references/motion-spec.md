# Path 动效与取值表

> 文档类型：取值规格。适用范围：`assets/path-kit/path-kit.js` 里的 `motion` 和 `path-kit.css` 里的变量，两处的数字以本表为准。
> 核对基线：2026-11-14 逐帧测量 + 开源复刻源码；第 1 节的图标个数、半径、镜像、键盘和第 6 节的强度，是同日在内置浏览器里用 motion-probe 对 path-kit 量过的。第 1 节「展开到一半就收」和第 8 节零件的默认值是 2026-11-15 加的，同样在浏览器里核对过。来源标记：**码** = 开源复刻代码（AwesomeMenu、DCPathButton、TimeScroller，不是 Path 官方代码）；**测** = 录屏逐帧实测（约 30 帧/秒，±33ms）；**估** = 素材里没量准，按观感估的。

## 6. 强度管什么

`setIntensity(k)` 的 k 在 0～1 之间。系统开了「减少动态效果」时 k 恒为 0，所有时长压到 120ms 以内，而且零件不再移动、缩放、转动：飞进来、长出来、掉进来换成原地淡入，飞走、摔出去换成原地淡出，鼓一下换成亮度闪一下，转动直接到位。压印加载照样轮流变深。这套替换借自 apple-design 的「减少动效是替换，不是删除」。

| 跟着 k 缩放 | k = 1 | k = 0.4 | 不跟着缩放（为什么） |
| --- | --- | --- | --- |
| 菜单冲过头 / 回落 | +10 / -5px（角落 +20 / -10） | +4 / -2px | 时长：节奏是 Path 的辨识度，克制靠幅度不靠快慢 |
| 菜单自转 | 360°（角落 180°） | 144°（72°） | 位移距离：图标从哪来、到哪去要看得懂 |
| 选中放大 | 3 倍 | 1.8 倍 | 加号转成叉：-135° 和 -45° 都落成叉，减了就不是叉 |
| 弹窗摆动 | -4° / +3° / -1° | -1.6° / +1.2° / -0.4° | 弹窗掉落和摔出的距离：仍从容器上方进、从底部出 |
| 弹窗摔出歪斜 | 8° | 3.2° | 压暗深浅：不是动效，用 `scrim` 单独调 |
| 回应、星标、冒出来的弹跳 | 1.15 / 1.35 / 1.2 倍 | 1.06 / 1.14 / 1.08 倍 | 滚动时钟：本来就不弹，强度对它没影响 |

### 7.3 不是取色的值

`path-kit.css` 里另有两组不是取色的值：
- **深色主题**（`data-pk-theme="dark"` / `"auto"`、`.dark` 下）：Path 没有深色模式，全是自定的。
- **纸上淡底、分隔线、桌面衬底**（`--pk-wash`、`--pk-rule`、`--pk-desk`）：给整站页面用的，也是自定的，见 [design-system.md](design-system.md)。

## 8. 零件的默认值

组件都由零件拼成（`path-kit.js` 第 0 节）。零件的默认值从最接近的 Path 组件借来，用在 Path 没有的东西上。

| 零件 | 默认 | 借自 |
| --- | --- | --- |
| `fly` | 300ms、线性，冲过头在 0.5、回落在 0.7 | Path 4 菜单的节奏（码） |
| `flyFrom` | 冲过 6px、回落 3px，0.4 → 1 倍，前 20% 淡入，不转 | 菜单节奏；冲过头减到菜单的六成，因为飞的通常是比图标大的东西（估） |
| `flyTo` | 先退 8px（0.25），ease-in 加速，→ 0.3 倍，最后 40% 淡掉，320ms | 菜单收回「先往外退再回去」、弹窗摔出「越落越快」（估） |
| `growFrom` / `shrinkTo` | 0.92 → 1、200ms、ease-out / → 0.96、150ms、ease-in | 情绪回应浮层（测 200ms 淡入；缩放是估） |

| `fadeIn` / `fadeOut` | 200ms ease-out / 300ms ease-in-out | 滚动时钟的出现和消失（码） |

| `rubber` | 最多 150px、阻力 0.8 | 下拉刷新（估） |

## 9. 怎么再量

**量 Path 原版**（补测一个效果）：

1. 在内置浏览器里打开任意 `web.archive.org` 的页面（必须同源，canvas 才能读视频帧）。
2. 把 [../scripts/frame-sheet.js](../scripts/frame-sheet.js) 的内容粘进去执行，再调用 `PathFrames.sheet('menu', 0, 0.4, 10, 5, 160, 0.55, 0.95)`。参数依次是：哪段录屏、起止秒、几帧、几列、每帧宽、上下裁切比例。
3. 截图看网格；要更细就缩小时间段、放宽每帧。录屏 ID 和名字都在脚本里。
4. 量完改本表，再同步改 `motion` 和 CSS 变量。

**取色**（第 7 节的做法）：

1. 下载到本机的录屏（地址见 essence.md「素材」）用无头 Chrome 取单帧：页面本身要放在 `file://` 下（`about:blank` 里加载不了本机视频），放一个 `<video>`，设 `currentTime` 等 `seeked` 以后，对视频元素截图，得到原尺寸的 PNG。在线录屏用上面的 `frame-sheet.js`。
2. 用 PIL 在色块或字形上开一个小窗（半径 8–14px），只留饱和度 > 0.3 的像素取中位数。字和灰色元素改取最暗的 15%，记下「字芯偏深」。
3. 同一个颜色在两三帧里各取一次，差在 ±10 以内算稳定。

**量自己的复刻**（核对像不像）：

1. 打开页面，把 [../scripts/motion-probe.js](../scripts/motion-probe.js) 粘进去执行。
2. 定格取样，例如发布菜单：

   ```js
   const rows = await PathProbe.scrub('.pk-menu-item', () => document.querySelector('.pk-menu-toggle').click(),
                                      { ms: 400, step: 10, origin: '.pk-menu-toggle' });
   PathProbe.peaks(rows);
   ```

3. 对照本表：Path 4 原样应在约 150ms 冲到 130、300ms 停在 120、终点自转 0、角度 -60°…60° 每隔 30°。
4. 关的时候也量一遍（再点一次加号、Esc、选中一项），并在「打开到一半」时关一次。`peaks` 里的 `startJump` 应该全是 0 或 null：不是 0，就是动画开头先跳了一下。常见原因是带 `delay` 的动画用了 `fill: 'forwards'`（等待期间回到原样），或者没从当前位置接着走。
5. 页面在后台（内置浏览器面板收起）时时间轴不走，`scrub` 照样能量；要看「收起以后」的状态，先调 `PathProbe.flush()`。
